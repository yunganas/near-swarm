# Shill on job 3

- **What it is:** NEAR Chain Signatures let a NEAR account sign transactions for other blockchains (like Bitcoin or Ethereum) without holding those chains’ private keys directly.
- **How it works:** The signing key is split across a decentralized network of nodes using MPC, so no single node ever has the full key.
- **Why it matters:** It lets NEAR users interact with other chains from one account, reducing the need for traditional bridges or managing many separate wallets.
